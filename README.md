# מרחב משימות

מערכת אישית לניהול משימות בעברית (RTL) עם סוכן AI מובנה.

- **מרחבים** עם צבע ותצוגה לבחירה: קנבן (גרירה ושחרור), רשימת TODO, לוח שנה חודשי.
- **דשבורד** עם דחוף / להיום / באיחור וכרטיס סיכום לכל מרחב; בחירת המרחבים נשמרת.
- **סוכן** (OpenAI, מודל `gpt-6-luna`) עם 5 כלים: קריאה, הוספה, עדכון, מחיקה וסיכום. פועל רק על הטווח שנבחר, ומבקש אישור לפני מחיקה או פעולה על יותר מ-3 משימות.
- סיסמה אחת לכניסה.

## Stack
Next.js 15 (App Router) · React 19 · Postgres (`pg`) · OpenAI SDK · Vercel

## משתני סביבה
ראו `.env.example`:

| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI |
| `APP_PASSWORD` | סיסמת הכניסה למערכת |
| `OPENAI_MODEL` | (אופציונלי) מזהה מודל, ברירת מחדל `gpt-6-luna` |

## הרצה מקומית
```bash
npm install
cp .env.example .env.local   # ומלאו ערכים
npm run seed                 # נתוני דוגמה (אפשר --force לאיפוס)
npm run dev
```
הטבלאות נוצרות אוטומטית בבקשה הראשונה.
